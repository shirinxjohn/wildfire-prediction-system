# Wildfire Risk Prediction & Vegetation Impact Analysis

A machine learning-based wildfire prediction system using environmental, temporal, and human activity features.

## Features
- Wildfire risk prediction using Random Forest and XGBoost
- Vegetation loss estimation using NDVI change analysis
- Heatmap visualization for high-risk zones
- Streamlit-based interactive UI

## Tech Stack
- Python
- Scikit-learn
- XGBoost
- Pandas
- NumPy
- Streamlit
- Matplotlib

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
